## 1. 目标

交付 **真·多人在线骨架** 与 **社交玩法闭环**，使多账号可在分片部署下稳定互助、偷菜与日常领取。

1. **多实例 Gateway + FarmServer 分片（先 2 物理实例）**：逻辑分片固定 `hash(uid) % 1024`，路由表映射到物理 Farm；Gateway 任意接入 + 连接注册表回推  
2. **跨农场总线默认 Kafka**：测试可注入内存 `EventBus`；禁止 Actor 同步调用另一 Actor  
3. **好友互助**：浇水 / 除草 / 除虫（三段式预占→裁决→结算）  
4. **偷菜 + 狗**：40% 上限、一轮一次、拦截赔付冻结（`1411` / `1412`）、基础狗启用/喂狗/买狗  
5. **FriendList 可偷摘要**（Redis 弱一致）  
6. **按用户名精确搜索**加好友  
7. **薄任务 + 邮件附件 + 每日登录奖励**

**成功标准：**

- 双 Gateway + 双 Farm + Kafka + 共享 MySQL/Redis 下：落在不同逻辑片的 A/B 可加好友、拜访、互助、偷菜（含狗拦截与赔付）、房间内可见 Delta  
- 偷菜额度竞争与收获竞争符合 protocol 第 6 章场景  
- FriendList 在成熟可偷变化后最终显示可偷提示  
- 用户名精确搜索可找到玩家并加好友；不存在用户有明确错误；搜索受限流  
- 每日登录与任务奖励可领取且同一服务器本地自然日幂等
- 单测覆盖三段式状态机（内存总线）；集成/smoke 覆盖 Kafka 主路径

## 4. 拓扑与路由

```text
Client ──WS/HTTP──▶ Gateway ×N（无状态：鉴权、限流、路由、连接注册）
                         │
                         │ logicalShard = hash(uid) % 1024
                         │ physical    = routeTable[logicalShard]
                         ▼
              FarmServer ×2（有状态 Actor；先两片对半映射）
                         │
              CrossAction / CrossResult ──▶ Kafka（默认）
              FarmDelta 推送 ──▶ 查连接注册 ──▶ 对应 Gateway ──▶ Client

共享：MySQL（权威）+ Redis（会话、可偷摘要、路由表缓存、连接索引）
```

### 4.1 农场权威路由

- **算法**：`shard = hash(uid) % 1024` → 查路由表 → 物理 FarmServer（架构 D4）  
- 期 4 路由表可静态配置，例如逻辑片 `[0,511]→farm-0`，`[512,1023]→farm-1`  
- 扩容只改路由表映射，不改哈希函数；热迁移实现后置  

### 4.2 Gateway 连接路由

- 客户端可连 **任意** Gateway；`ws_url` 由登录/配置下发（可负载均衡）  
- 每条 WS 在 Redis（或等价）登记：`uid/connId → gatewayId`  
- Farm 广播 Delta / 个人推送时按注册表投递到正确 Gateway  
- **不做** 按好友亲和或一致性哈希直接绑物理机（避免迁移动荡）  

### 4.3 事件总线

- 接口：`EventBus.Publish/Subscribe`（或按目标分片消费）  
- 生产默认：**Kafka**；单测/部分 smoke：**内存总线**  
- 分区键建议 `owner_uid`（或目标逻辑片），保证同一主人农场跨农场消息有序  
- at-least-once：主人侧 `req_id` LRU(64) 去重  

### 4.4 好友与搜用户

- `friendship` / `player` 仍在共享 MySQL（期 3 已有）  
- 期 4 Gateway 或薄 Social 模块读写均可，但分片键语义保持「好友权威不按单 uid 分片」  
- 搜用户名：精确匹配 `account.username` / 关联 player，返回 `uid+nickname[+already_friend]`

## 5. 跨农场协议（互助）

对齐 `architecture.md` §7.2。

### 5.1 三段式

1. **访客 Actor 预占**：校验好友、维护次数上限等；写入 `pending[req_id]`；发 `CrossAction` 后立即返回（不阻塞 mailbox）  
2. **主人 Actor 裁决**：`req_id` 去重 → `advance` → Validate/Commit → 房间 `FarmDelta` → `CrossResult`  
3. **访客 Actor 结算**：成功发奖并清 pending；失败/超时回滚预占 → 应答客户端  

超时：**5s** → 回滚 → `ERR_TIMEOUT`（1004）。

### 5.2 动作与预占

| 动作 | 预占 | 成功 | 失败 |
| --- | --- | --- | --- |
| 浇水 | 维护计数 +1 | +2 经验 | 计数 −1 |
| 除草 / 除虫 | 同上 | +2 经验 + 5 金币（按策划） | 计数 −1 |

仅 `FRIEND`；对自己农场仍走本地写路径（期 2/3），不发 CrossAction。

客户端：拜访态开放这三工具；等 Rsp；他人靠 FarmDelta 看见。

## 6. 偷菜与狗

### 6.1 偷菜

- 命令：`Steal`（222）；跨农场三段式，`kind=Steal`  
- 成熟地；`FinalYield` 固化后额度 = floor(产量 × 40%) − 已偷  
- 数量：`rand(1..10)` 再截断剩余额度  
- 单访客每 `HarvestRound` 每地块最多成功一次 → `1409`  
- 额度耗尽 → `1410`；偷自己 → `1408`；非好友 → `1401`  
- 与主人收获竞争：已收 → `1216`  
- 成功：果实入访客仓；**不给经验**；解冻预冻金  

### 6.2 狗与赔付

- 启用中的狗且狗盆有粮才生效；空盆拦截率 = 0  
- 期 4：可买/启用至少一种基础狗；拦截率按策划表（升级树可后置，等级 0 基础率必须正确）  
- 发起前访客预冻「果实单价 × 10」；不足 → `1412 ERR_STEAL_NO_AFFORD`  
- 拦截 → `1411`：不返还本轮机会；冻结改实扣并转给主人；Rsp 带赔付与 `dog_type`  
- 本分片命令：`PetStatus` / `PetActivate` / `PetFeed`；买狗/狗粮走商店扩展  

### 6.3 可偷摘要

- 成熟可偷状态变化时异步写 Redis（如 `steal_hint:{uid}`）  
- `FriendList` 批量读取；弱一致可接受

## 7. 搜索、任务、邮件、每日登录

### 7.1 SearchUser

- 新命令建议 **`SearchUser = 410`**（写入 `protocol.md`）；body：`{ username }`  
- 精确匹配；命中返回 uid/nickname；未命中明确错误（可用 `1002` 或社交段约定码，实现时钉死并入库）  
- 限流防枚举；成功后客户端调现有 `AddFriendByUID`  

### 7.2 任务

- 按服务器 `time.Local` 的自然日（本地 00:00）初始化 4 条固定任务：播种、收获、拜访好友农场、每日登录；`TaskList` 返回 `reset_at`
- 播种、收获、拜访由本分片玩法事件推进；每日登录 task_id=4 初始化即完成
- `TaskClaim` 直接入账；领取幂等，任务奖励不进邮件

### 7.3 邮件

- `MailList` + 附件领取；仅系统、管理员等邮件使用该入口，不承载任务或每日登录奖励
- 存储按 uid；可与玩家库同实例，接口独立  

### 7.4 每日登录

- `ClaimDailyLogin`（614）保留为 task_id=4 的兼容领取入口
- 与 `TaskClaim(task_id=4)` 共享服务器本地自然日状态；重复 → `ERR_DUPLICATE_OK`（1005）

个人奖励变化需要时经 `PlayerDelta` 或 Rsp patch 通知（与 protocol 5.x 一致），不塞进 FarmDelta。

## 8. 客户端

- 拜访：开放浇水/除草/除虫/偷菜；仍隐藏播种等主人专属写  
- 跨农场等 Rsp；偷菜不做数量乐观预测；被抓展示赔付  
- 好友面板：可偷标记、用户名搜索、保留 uid/链接  
- 任务 / 邮件 / 每日登录入口  
- 狗：状态、喂狗、启用；商店买狗与狗粮  
- 多 Gateway：断线用会话重连任意 Gateway，再 Enter/Sync

## 9. 验收与测试

### 9.1 必须场景

1. 跨片 A/B：加好友 → 拜访 → 互助成功与失败回滚  
2. 偷菜额度竞争（多人同时偷，总量 ≤ 40%）  
3. 收获 vs 偷菜竞争（`1216` 或成功偷）  
4. 狗拦截：`1411` + 金币转给主人；余额不足 `1412`  
5. FriendList 摘要最终一致到可偷  
6. 用户名搜索 + 加好友；限流冒烟  
7. 每日登录 / 任务领奖幂等  

### 9.2 测试策略

- 单元：内存 EventBus 测三段式状态机、去重、超时回滚  
- 集成：compose 起 Kafka + 双 Farm + 双 Gateway  
- smoke：扩展 `smoke` 子命令覆盖互助/偷菜；浏览器双账号演示剧本  

### 9.3 演示剧本

两浏览器（可打到不同 Gateway）：注册 → 搜用户名加好友 → 拜访 → 互助 → 有狗/无狗偷菜 → 领每日登录与任务邮件。
