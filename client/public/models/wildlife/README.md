# Wildlife model assets

- `bunny.glb` and `caterpillar.glb` come from Kenney's Cube Pets pack.
- Source: https://kenney.nl/assets/cube-pets
- License: Creative Commons Zero 1.0 (see `KENNEY-LICENSE.txt`).

The models are served locally and loaded with Three.js `GLTFLoader`; no runtime
request is made to an external asset host.
