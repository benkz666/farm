Social 的 `107,000 QPS` 由两部分组成：四个直接社交接口共
`47,666.67 QPS`，以及进入好友农场和四个跨农场操作产生的
`59,333.33 QPS` 关系校验。

MySQL 与 Redis 的命令量不在映射表中预先硬编码倍数。缓存命中、异步批量、
Journal 合并和投影批次都会改变“一个业务请求对应几条命令”，因此本轮直接用
MySQL Questions/TPS、Redis commands、缓存命中率以及 Journal/Projection 计数器
实测，避免用静态倍数产生更大误差。

Gateway 的非业务负载另算：在标准单元下，30 秒心跳对应每秒约 4,000 个
Ping 和 4,000 个 Pong 帧；新会话约 100 次/秒，0.1%/分钟重连约 2 次/秒。
